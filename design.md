# Entanglement Trap design

The submission is an experiment workbench. The first screen asks one question
and gives one action: choose a probe and play. Results lead into proof, then
the comparison registry. The companion Entangle Lab is the teaching on-ramp.

Use the existing dark ink, amber action, and blue data tokens in `main.css`.
Display and body type use the existing Chivo/Archivo stack; exact data use the
mono stack. Use the existing four-point spacing scale and square edges.

Keep copy short and literal. Every displayed result keeps its evidence kind.
Plots show compact labels; expandable ledgers retain full precision.
Do not invent outcomes, claims, adoption metrics, or hardware results.

Scientific figures are stationary. Hover and focus identify controls; state
changes explain what happened. Honor reduced motion. Wide figures may scroll
inside their own containers; the page itself must fit a narrow screen.

The Qollab entry remains a body fragment. `preview.html` is a separate local
shell with correct encoding and an explicit notice that live runs need Qollab.
